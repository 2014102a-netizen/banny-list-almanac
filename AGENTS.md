# Банный лист · Альманах

Мобильная культурная афиша Петербурга для друзей. Основной язык русский. Название группы «Банный лист», участники банщики. «Глистогон» — отдельная главная тема Telegram; публикации альманаха идут в тему «Альманах» 88757 группы -1001178604122.

## Стек и данные

React, Vite, Tailwind, JSX. Страница для GitHub Pages. Apps Script обслуживает публичную афишу и закрытые отметки из одной Google Таблицы. Таблица остаётся закрытой. Вкладки: События, Выпуски, Участники, Отметки. Пароль и сессии существуют только в серверном Apps Script и браузерной сессии; паролей в GitHub нет. Имена и голоса отсутствуют в публичном GET и снимке.

Данные для примера берутся из проверенных выпусков telegram-almanac. Постоянный ID события включает дату; повторный выпуск сохраняет ID. Существующие отметки при обновлении афиши сохраняются. Номер выпуска связан со списком ID. Одну постановку в разные дни учитывать как отдельные события.

## Вкус и оформление

Следовать ../telegram-almanac/EDITORIAL.md. Зарубежные концерты, особые клубные события, современный театр и выставки. Исключать каверы, трибьюты, органы при свечах и стандартный классический репертуар.

Тёплая светлая бумага, тёмные чернила, зелёный акцент. Выразительная журнальная типографика, собственный знак листа, минимум декоративных контейнеров. Все цвета через CSS-переменные. Медиа только через src/config/media.js. Ссылки проекта через src/config/catalog.js. Мобильный интерфейс проверять на 390px, крупные цели нажатия, доступные диалоги, reduced motion.

## Проверка

npm run build; npm test. Проверять вход, ошибку пароля, закрытость имён без входа, сохранение/изменение отметки, архив, фильтры, прямую ссылку события и мобильный экран. Сбой API показывает дату сохранённой афиши. Успешное сохранение подтверждает сервер.

29.10.2026: добавлены самостоятельные предложения участников. Вкладка «События участников» (1888777701) хранит записи A:X: A:Q — схема афиши, R — imageUrl, S — memberId, T/U — даты, V — published/withdrawn, W — requestId, X — revision. Авторство, ключ повторного запроса и версии доступны только с сессией. Публичный GET включает origin=community, без личных полей. Apps Script версия 4, прежний URL API.

Форма «Добавить событие»: ссылка → извлечение Open Graph/Schema.org Event → редактируемый предпросмотр → подтверждение даты/места → публикация. Обязательны название, дата, место и HTTPS-ссылка. Парсер работает после входа; закрытая страница ведёт к ручному заполнению. Голоса общие. Дубли по URL без UTM и дате открывают существующую карточку. Повтор запроса создания идемпотентен, правки проверяют автора и revision, снятие хранит строку withdrawn.

Текущий выпуск объединяется с будущими предложениями независимо от issue.eventIds. «От банщиков» фильтрует предложения; «Прошедшие» сохраняет карточки и голоса по завершении дня (endDate/date, Москва). Исторический выпуск использует свой список ID. «Интерес группы» сортирует по going, затем interested. Новые категории: meeting/festival/other. Имена авторов и количества голосов видны после входа.

Еженедельные правила в ../telegram-almanac/EDITORIAL.md и WEB_APP.md дополнены: все действующие предложения в окне выпуска включаются отдельным блоком, со своими ID. tools/sync_sheet.py пишет только редакционные события и выпуски; отдельную вкладку предложений сохраняет. tools/community_candidates.py получает кандидатов из свежего публичного API.

Проверка: серверные и календарные тесты, 2 теста недельной синхронизации, production build, мобильный сценарий на 390px (вход, извлечение, создание, голос, правка, перезагрузка).
