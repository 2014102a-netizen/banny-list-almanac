# Банный лист · Альманах

Мобильная культурная афиша Петербурга для друзей. Основной язык русский. Название группы «Банный лист», участники банщики. «Глистогон» — отдельная главная тема Telegram; публикации альманаха идут в тему «Альманах» 88757 группы -1001178604122.

## Стек и данные

React, Vite, Tailwind, JSX. Страница для GitHub Pages. Apps Script обслуживает публичную афишу и закрытые отметки из одной Google Таблицы. Таблица остаётся закрытой. Вкладки: События, Выпуски, Участники, Отметки. Пароль и сессии существуют только в серверном Apps Script и браузерной сессии; паролей в GitHub нет. Имена и голоса отсутствуют в публичном GET и снимке.

Данные для примера берутся из проверенных выпусков telegram-almanac. Постоянный ID события включает дату; повторный выпуск сохраняет ID. Существующие отметки при обновлении афиши сохраняются. Номер выпуска связан со списком ID. Одну постановку в разные дни учитывать как отдельные события.

## Вкус и оформление

Следовать ../telegram-almanac/EDITORIAL.md. Зарубежные концерты, особые клубные события, современный театр и выставки. Исключать каверы, трибьюты, органы при свечах и стандартный классический репертуар.

Тёплая светлая бумага, тёмные чернила, зелёный акцент. Выразительная журнальная типографика, собственный знак листа, минимум декоративных контейнеров. Все цвета через CSS-переменные. Медиа только через src/config/media.js. Ссылки проекта через src/config/catalog.js. Мобильный интерфейс проверять на 390px, крупные цели нажатия, доступные диалоги, reduced motion.

## Проверка

npm run build; npm test. Проверять вход, ошибку пароля, закрытость имён без входа, сохранение/изменение отметки, архив, фильтры, прямую ссылку события и мобильный экран. Сбой API показывает дату сохранённой афиши. Успешное сохранение подтверждает сервер.
