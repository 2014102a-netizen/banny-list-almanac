# Банный лист · Альманах

Мобильная культурная афиша Петербурга. Концерты зарубежных исполнителей, особые клубные ночи, современный театр, выставки и инсталляции.

Афиша открывается по ссылке. После входа по общему паролю участник выбирает имя и отмечает «Интересно», «Пойду» или «Пропускаю». На карточке видна компания. Архив сохраняет предыдущие выпуски. Отметки связаны с постоянными ID событий.

## Устройство

React, Vite, Tailwind CSS, JSX. Статический сайт публикуется на GitHub Pages из папки `docs/`. Данные поступают из закрытой Google Таблицы через Google Apps Script. Локальный снимок показывает афишу при сбое связи с указанием даты.

Google Таблица содержит четыре вкладки: События, Выпуски, Участники, Отметки. Открытый GET отдаёт события и выпуски. Закрытые POST-запросы проверяют серверную сессию. Секреты и имена участников отсутствуют в статическом сайте.

Общий пароль и выбор имени рассчитаны на доверительный круг. Сессия сохраняется в текущей вкладке браузера. Пароль в браузерном хранилище отсутствует.

## Разработка

```bash

```

## Настройка Apps Script

1. В Google Таблице открыть «Расширения → Apps Script».
2. Вставить `apps-script/Code.gs`. Проверить ID своей таблицы в `SPREADSHEET_ID`.
3. В «Настройках проекта → Свойства скрипта» владелец задаёт `GROUP_PASSWORD`. Пароль сообщается участникам отдельно.
4. Развернуть веб-приложение: запуск от имени владельца, доступ для всех. Разрешение скрипту на Google Таблицы подтверждает владелец.
5. URL, заканчивающийся на `/exec`, указать в `public/config.js` как `window.ALMANAC_API`. Секреты в этот файл не добавлять.
6. Выполнить сборку, скопировать `dist/` в `docs/`, добавить `docs/.nojekyll` и опубликовать изменения.

В GitHub Pages выбрать `main` и `/docs`. Изменения событий в таблице появляются после обновления страницы; открытая вкладка опрашивает сервер раз в минуту.

## Проверка

Тесты проверяют закрытость участников и отметок, неверный пароль, сессии, изменение и снятие голоса, постоянные ID, архив и фильтры. Реальное сохранение подтверждается после развёртывания Apps Script в Google.

Ссылки на источники, даты проверки и условия билетов находятся в карточках событий. Цена и наличие уточняются у продавца.
