# Банный лист · Альманах

Мобильная культурная афиша Петербурга. Концерты зарубежных исполнителей, особые клубные ночи, современный театр, выставки и инсталляции.

Афиша открывается по ссылке. После входа по общему паролю участник выбирает имя и отмечает «Интересно», «Пойду» или «Пропускаю». На карточке видна компания. Архив сохраняет предыдущие выпуски. Отметки связаны с постоянными ID событий.

## Устройство

React, Vite, Tailwind CSS, JSX. Статический сайт публикуется на GitHub Pages из папки `docs/`. Данные поступают из закрытой Google Таблицы через Google Apps Script. Локальный снимок показывает афишу при сбое связи с указанием даты.

Google Таблица содержит пять вкладок: События, Выпуски, Участники, Отметки, События участников. Открытый GET отдаёт события и выпуски. Закрытые POST-запросы проверяют серверную сессию. Секреты и имена участников отсутствуют в статическом сайте.

Общий пароль и выбор имени рассчитаны на доверительный круг. Сессия сохраняется в текущей вкладке браузера. Пароль в браузерном хранилище отсутствует.

## Разработка

```bash
npm ci
npm run dev
npm test
npm run build
```

## Настройка Apps Script

1. В Google Таблице открыть «Расширения → Apps Script».
2. Вставить `apps-script/Code.gs`. Проверить ID своей таблицы в `SPREADSHEET_ID`.
3. В «Настройках проекта → Свойства скрипта» владелец задаёт `GROUP_PASSWORD`. Пароль сообщается участникам отдельно.
4. Развернуть веб-приложение: запуск от имени владельца, доступ для всех. Разрешения скрипту на Google Таблицы и чтение внешних страниц подтверждает владелец.
5. URL, заканчивающийся на `/exec`, указать в `public/config.js` как `window.ALMANAC_API`. Секреты в этот файл не добавлять.
6. Выполнить сборку, скопировать `dist/` в `docs/`, добавить `docs/.nojekyll` и опубликовать изменения.

В GitHub Pages выбрать `main` и `/docs`. Изменения событий в таблице появляются после обновления страницы; открытая вкладка опрашивает сервер раз в минуту.

## Проверка

Тесты проверяют закрытость участников и отметок, неверный пароль, сессии, изменение и снятие голоса, постоянные ID, архив и фильтры. Реальное сохранение подтверждается после развёртывания Apps Script в Google.

Ссылки на источники, даты проверки и условия билетов находятся в карточках событий. Цена и наличие уточняются у продавца.

## Добавить событие

После входа нажать «Добавить событие», вставить HTTPS-ссылку и получить черновик. Проверить название, дату, место и цену, выбрать категорию и при желании написать «Почему зову». Подтвердить публикацию. Карточка появляется сразу; автор может исправить или снять её. Повторная ссылка на ту же дату открывает существующее событие.

Сервер извлекает Open Graph и единственный Schema.org Event. Когда страница закрыта или отдаёт мало данных, поля заполняются вручную. Дату и условия подтверждает автор. Поддержаны концерт, ночь, театр, выставка, встреча, фестиваль и другое событие.

«От банщиков» показывает предложения участников. «Интерес группы» сортирует по числу «Пойду», затем «Интересно». «Прошедшие» сохраняет завершившиеся события и их отметки. Для ночей и нескольких дней нужно указать дату завершения. Дата сменяется по Москве. Выпуски в архиве сохраняют свои списки событий.

Четверговый сборщик получает свежий публичный каталог и включает актуальные предложения в отдельный блок выпуска, сохраняя ID. `tools/sync_sheet.py` обновляет редакционную афишу и выпуски; отдельная вкладка предложений сохраняется. Выборка по датам: `python3 tools/community_candidates.py --start YYYY-MM-DD --end YYYY-MM-DD --output /tmp/community.json`.

Структура вкладки предложений: A:Q соответствует событиям, R — изображение, S — ID автора, T/U — создание/обновление, V — published/withdrawn, W — ID запроса, X — версия. Личные S/W/X отсутствуют в публичном API. В `tests/harness.mjs` находится изолированная фикстура с тестовым паролем. Локальная проверка формы: `node tools/dev_community.mjs` и `npx vite --config vite.community.config.js --host 127.0.0.1 --port 4173`. Данные проверки хранятся в памяти. Проверка недельной синхронизации: `python3 -m unittest discover -s tests -p 'test_*.py'`.
